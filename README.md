# Al-Farida Global B2B Agricultural Export Portal
# بوابة الفريدة العالمية للتصدير وفرز وتعبئة الحاصلات الزراعية

Official bilingual (Arabic / English) B2B export showcase and direct RFQ portal for **Al-Farida for Agricultural Export, Sorting & Packing (شركة الفريدة للتصدير وفرز وتعبئة الحاصلات الزراعية)** — Egypt.

البوابة الرسمية ثنائية اللغة (عربي / إنجليزي) لشركة **الفريدة للتصدير وفرز وتعبئة وتبريد الحاصلات الزراعية** من مصر إلى الأسواق الأوروبية والخليجية والعالمية.

## Overview | نبذة عن المنصة

* **Bilingual B2B Interface:** Instant Arabic (RTL) and English (LTR) language switching.
* **10 Core Export Crops:** Fresh Valencia & Navel oranges, fresh & -40°C IQF strawberries, Wonderful pomegranates, seedless table grapes, mangoes, PFA potatoes, red/golden onions, garlic, and IQF frozen vegetables.
* **Importer Tools:** Real-time search by crop name or HS Code, multi-crop RFQ basket, 12-month seasonal availability calendar, printable PDF technical specification sheet, and direct WhatsApp / Email RFQ dispatch.
* **Quality & Cold Chain:** Highlights optical laser sorting, stainless-steel washing conveyors, -40°C IQF freezing tunnels, 4-tier cold storage, and full export documentation (GlobalG.A.P, ISO 22000, BRCGS, EUR.1, MRL Lab, ISPM-15).

## Hosting & Deployment | النشر والاستضافة

This portal is a static web package and deploys directly on **GitHub Pages** or **Cloudflare Pages** with zero build steps:

1. Ensure the main file is named `index.html` in the root directory alongside `privacy.html`.
2. Push files to the `main` branch of a public GitHub repository.
3. Open **Settings → Pages**, set the publishing source to `main` / `/ (root)`, save, and enable **Enforce HTTPS**.
4. Optionally connect a custom domain (e.g., `alfarida-eg.com`) under **Custom domain**.
